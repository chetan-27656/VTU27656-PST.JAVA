# Week 1: Java Fundamentals

Welcome to Week 1 of the VTU27656-PST JAVA course!

## 📚 Topics Covered

This week focuses on fundamental Java programming concepts:

- **Java Basics**: Variables, data types, operators
- **Control Flow**: If-else statements, loops (for, while, do-while)
- **Methods**: Function definition, parameters, return values
- **Arrays**: Single and multi-dimensional arrays
- **Object-Oriented Programming Basics**: Classes and objects

## 📂 Contents

All Java source files and assignments for Week 1 are contained in this directory.

### How to Compile and Run

```bash
# Navigate to Week1 directory
cd Week1

# Compile a Java file
javac FileName.java

# Run the compiled program
java FileName
```

## 🎓 Learning Objectives

By the end of Week 1, you should be able to:
- Write basic Java programs
- Understand and use variables and data types
- Implement control flow structures
- Create and use methods
- Work with arrays

## 📝 Assignments

Review the assignment files in this directory for specific tasks and exercises.

## 💡 Tips

- Always follow Java naming conventions (camelCase for variables/methods, PascalCase for classes)
- Comment your code for clarity
- Test your programs with various inputs
- Debug using print statements or a debugger
